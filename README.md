# sunta.studio

Official website of SUNTA STUDIO — Games, stories & weird ideas.

Static site (no build step), served by GitHub Pages from `main` / root.

- `index.html` — the home page (one page)
- `roadmap/index.html` — public roadmap (/roadmap/)
- `assets/` — official logos, pixel characters, OGP image, favicons
- `CNAME` — custom domain for GitHub Pages
- `.nojekyll` — serve files as-is

To update: change files, merge to `main`; Pages redeploys in a minute or two.
